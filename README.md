One letter that describes the day, written for make.fun's "One Letter for Your Day" bounty:

> **K** — for *knackered*: utterly spent after a day of hard, nonstop work. A day of bounty after bounty, built and submitted from before dawn, ending with shoes still on and nothing left in the tank.

The entry program writes that single letter to `/output/entry.txt` — exactly one byte, one letter A–Z, no word, no gloss, no punctuation, no trailing newline. It also self-checks the gate (file must be exactly 1 UTF-8 character, a single letter A–Z) before exiting.

## Run it

```sh
python3 main.py
```
